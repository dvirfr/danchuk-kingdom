# Danchuk's Enchanted Kingdom

A private birthday web app. React + Vite + Firebase (Auth + Firestore), deployed to GitHub Pages.

- No personal content lives in this repo. Coupons, photos and notes are stored in Firestore behind security rules (`firestore.rules`).
- `npm run dev` for local development (sign-in works on `localhost`).
- Pushes to `main` deploy automatically via `.github/workflows/deploy.yml`.
